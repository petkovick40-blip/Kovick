# Kovick — base decompilada para análise

Nome de exibição alterado para **Kovick** e ícones do launcher substituídos pela logo fornecida.

## Importante

Este pacote veio de arquivos decompilados de um APK. Ele **não é um projeto Android Studio completo** e ainda não está pronto para compilar ou gerar um APK. Não contém a estrutura Gradle original nem garante recursos de build reproduzíveis.

Antes de publicar, confirme que você tem os direitos sobre o aplicativo e todo o código/recursos incluídos. Revise também segredos, chaves, certificados, endpoints e dados privados. Não publique credenciais ou keystores.

Para gerar uma versão instalável confiável, será necessário reconstruir/recuperar a configuração de build e testar a recompilação.
